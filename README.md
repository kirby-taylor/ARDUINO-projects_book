# Arduino Projects Book

A collection of projects completed while working through the Arduino Projects Book included with the Arduino Starter Kit.

This repository documents my progress learning Arduino, circuit design, embedded systems, and basic LTspice simulation. Each project is based on the exercises in the book and includes documentation of the physical build, code, and circuit behavior.

## What's Included

Project folders may include:

- Arduino sketches
- Photos and videos of the completed circuit
- LTspice schematics and simulations
- Project-specific documentation

## About

These projects are based on the tutorials and exercises from the Arduino Projects Book and are not presented as original project designs. This repository is intended to document my learning process and will continue to grow as projects are completed.
